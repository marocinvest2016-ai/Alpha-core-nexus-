# Alpha Core Nexus — تطبيق عرض العقارات (كلاّ السّرحنا)

تطبيق Streamlit بسيط لعرض عقارات (أراضٍ زراعية، مزارع، قطع بناء، منازل/عمارات) في منطقة كلاّ السّرحنا.

ميزات النموذج:
- استيراد البيانات من `properties.json`
- فلترة حسب النوع، المنطقة، السعر، والمساحة
- عرض صور ومعلومات الاتصال
- عرض مواقع العقارات على الخريطة

كيفية التشغيل محليًا:
1. ثبّت المتطلبات:
   ```
   pip install -r requirements.txt
   ```
2. شغّل التطبيق:
   ```
   streamlit run app.py
   ```

إضافة عقار جديد:
- أضف عنصرًا جديدًا في مصفوفة `properties.json` متبعًا نفس البنية (id, title, type, location, latitude, longitude, area_m2, price_mad, description, images, contact_name, contact_phone, status, date_posted).

ملاحظات مستقبلية (تحسينات مقترحة):
- ربط بقاعدة بيانات SQLite أو PostgreSQL للحفظ الديناميكي.
- واجهة إدارية لإضافة/تعديل العقارات من داخل التطبيق.
- دعم لغتين (العربية/الفرنسية) والتعامل مع عملات مختلفة.
- رفع الصور محليًا أو على S3 بدل استخدام روابط خارجية.
